5 | Viewing and Interpreting Permission Strings
a) Create a file report.txt and a directory Data in your home directory.b) Display the permissions of both using ls -l.c) From the output, identify the file type, owner permissions, group permissions and others' permissions for report.txt.d) Interpret the following permission strings and write who can read, write and execute: 
-rwxr-xr--
drw-r-----
-rw-rw-rw-
-r--------
Answer:
a) touch ~/report.txt && mkdir ~/Data
b) ls -l ~/report.txt ~/Data
c) File type: - (regular file). Owner: rw- (read/write). Group: r-- (read). Others: r-- (read).
d) -rwxr-xr-- : Owner (read, write, execute). Group (read, execute). Others (read).
   drw-r----- : Owner (read, write). Group (read). Others (no permissions).
   -rw-rw-rw- : Owner, Group, Others can all read and write.
   -r-------- : Owner (read). Group and Others (no permissions).

14 | Write a script loops.sh that:
a) Displays numbers from 1 to 10 using a for loop.b) Displays the multiplication table of a number entered by the user (up to 10) using a for loop.c) Calculates and displays the sum of numbers from 1 to N (N entered by user) using a while loop.d) Run the script and display the output for each part.
Answer:
Script loops.sh content:
#!/bin/bash
# a) For loop
for i in {1..10}; do echo $i; done
# b) Multiplication table
read -p "Enter number: " num
for i in {1..10}; do echo "$num x $i = $((num * i))"; done
# c) While loop sum
read -p "Enter N: " n
sum=0; i=1
while [ $i -le $n ]; do sum=$((sum + i)); i=$((i + 1)); done
echo "Sum:" $sum

d) Run using: bash loops.sh
